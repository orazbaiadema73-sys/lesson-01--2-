# Expo mobile app

Бұл жоба Expo + React Native + TypeScript үшін дайын үлгі.

## Іске қосу
1. VS Code-та осы папканы ашыңыз.
2. Terminal → New Terminal таңдаңыз.
3. `npm install` орындаңыз.
4. `npx expo start` орындаңыз.
5. Android эмуляторын ашып, терминалда `a` басыңыз.

## Экрандар
- Login
- Forgot Password
- Register
- Verify Code

Растау кодының демо мәні: `1234`. Бұл оқу жобасының демонстрациялық нұсқасы, нақты SMS жібермейді.
